  项目定位

  多模型群聊协同平台，一个本地部署的 Web 平台，把 DeepSeek、豆包、Kimi、通义、文心、星火、Ollama 等 7
  家大模型放进同一个"群聊"里协作：用户提一个问题，多个模型各展所长、互相引用、辩论、分工，产出超越单一模型的答案。

  核心理念

  1. 模型即成员，群聊即工作流 — 用微信群的隐喻承载多智能体协作，全程可视化、可干预
  2. 强匿名盲评 — 所有模型（含主持人）只以显示名互称，不知道彼此真实身份；提示词约束 +
  系统级输出脱敏双保险，防止模型"慕强附和"，支持品牌偏见免疫的盲评实验
  3. 人在环中 — 随时插话、暂停、强制指令、@点名、编辑修正消息，管理员热改模型配置与协作策略
  4. 收敛保证 — 多层机制（干预预算、发言上限、协议标记、任务终态）确保群聊必然有限轮次结束

  四种协作模式

  - 自由讨论：匿名主持人引导+质量审核；任务调派：LLM
  拆解任务→看板→按能力/成本评级路由派单→顺序验收汇总；辩论：正反方严格交替+裁判四维评分终审；混合模式（开发中）

  主要创新

  1. 可编程发言权调度器 — 十级优先级的选人状态机，每一步决策实时推送前端可视化
  2. 协议标记驱动的结构化协作 — 用【任务-2-完成】【讨论结束】等自然语言标记承载状态同步，任何厂商模型天然兼容
  3. 面向国产异构 API 的容错体系 — 指数退避、失败跳过、主持人降级、告警分类码 +
  配套手册（真实沉淀过余额耗尽/鉴权坑/并发限制等事故）
  4. AgentPrune 上下文裁剪 — 4 种策略零 LLM 调用压缩长会话上下文，破解 O(n²) token 膨胀
  5. 全链路可观测 — 消息、token、选人决策、调用链路、安全审计全落库，可回放可恢复
